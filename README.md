NexusGram

NexusGram — Android-клиент на базе исходного проекта Telegram с собственной визуальной идентичностью и планами по развитию независимой серверной инфраструктуры.

Возможности проекта

- Android-приложение.
- Собственная идентичность NexusGram.
- Подготовка собственной backend-инфраструктуры.
- Разработка каталога подарков и панели администратора.
- Настройка собственной системы внутренних балансов и коллекционных предметов.

Сборка APK

Проект использует GitHub Actions.

Workflow: ".github/workflows/android.yml"

Чтобы запустить сборку:

1. Открой вкладку Actions.
2. Выбери NexusGram Android APK.
3. Нажми Run workflow.
4. Дождись завершения процесса.
5. Скачай "NexusGram-APK" из раздела Artifacts.

Исходный код

Исходники проекта размещаются в этом репозитории.

Файлы "nexusgram.part01"–"nexusgram.part09" используются для восстановления исходного архива перед сборкой.

Текущий статус

Проект находится в разработке. Независимый backend и полная миграция чатов, авторизации, медиа и уведомлений ещё требуют реализации и проверки.
