# WaysGram — статус исходников

## Что находится в этом архиве

- Полный исходный Android-проект с исходными экранами и навигацией.
- Имя приложения изменено на WaysGram в локализованных Android-ресурсах.
- Отдельный standalone launcher и самостоятельный `MainActivity` в основной APK не добавляются.
- `WaysGram-Backend/` содержит отдельный REST backend и SQLite-схему для данных, размещаемых на VDS.
- В Settings добавлен пункт «Панель разработчика», который открывает WebView-фрагмент внутри оригинального Telegram UI. Отдельный launcher не создаётся.

## Важное ограничение текущей сборки

Это подготовленный исходный проект с сохранённым интерфейсом и отдельным backend, но **полная миграция с Telegram MTProto на WaysGram API ещё не завершена**.

В исходном Android-клиенте авторизация, список чатов и ряд других операций по-прежнему используют Telegram MTProto. Поэтому текущая сборка не гарантирует, что пользовательские аккаунты, сообщения, контакты, каналы и связанные данные хранятся только на VDS. Для этого требуется последовательная замена сетевого слоя и моделей данных с тестированием каждой функции.

Не удаляйте оригинальные протокольные и лицензионные уведомления из исходного проекта.

## Безопасная схема входа через бота

Бот может доставлять собственный одноразовый код WaysGram пользователю после того, как тот сам запустил бота и подтвердил привязку Telegram-аккаунта. Код должен быть создан backend именно для входа в WaysGram и иметь короткий срок действия.

Бот не должен выдавать пользователю номер для перехвата кодов сторонних сервисов или пересылать ему произвольные входящие SMS-коды.

## Админ-панель

Пункт «Панель разработчика» подключён к странице `/admin` на VDS. Административный экран и backend используют согласованные маршруты `/api/admin/*`; backend поддерживает выдачу Stars, каталог подарков, создание и редактирование каналов, назначение владельцев и администраторов каналов, поиск пользователей, бан/разбан и статистику. Сессия администратора отдельная от пользовательской.

Для запуска backend администратор задаётся на VDS переменными окружения:

- `NEXUSGRAM_ADMIN_USER`
- `NEXUSGRAM_ADMIN_PASSWORD`

Значение пароля следует ввести непосредственно в защищённую конфигурацию VDS. Не храните пароль в APK, GitHub или файлах исходников. Тестовый код выдаётся только вошедшему администратору и только для номера из `NEXUSGRAM_TEST_PHONES`, когда `NEXUSGRAM_DEV_OTP=1`; в production этот режим должен быть выключен. Перед production используйте уникальный пароль и HTTPS.

## Сборка и проверка

GitHub Actions workflow `WaysGram Android APK` предназначен для сборки исходного Android-клиента без второго standalone launcher. Workflow `WaysGram Source ZIP` создаёт архив исходников.

Сборка APK не заменяет проверку установки, входа, сетевых запросов, хранения данных на VDS и восстановления резервных копий.
